Static review: packet lengths, magic, K and reserved bytes are validated;
RX is issued before TX; coherent DMA buffers are not mapped twice; calls are
serialized; existing file descriptors hold object references; failed DMA
termination quarantines allocations and callback storage instead of freeing
potentially active buffers. No source changes were necessary for Linux6.8.
Hardware binding, DMA interrupts, timeout recovery, reset GPIO polarity and
actual tile output still require board tests with the new DMA-capable overlay.
The existing voice-prototype overlay does not instantiate this tile driver.

The prebuilt module is unsigned. Load only for the exact matching running
kernel and intended overlay. A later kernel requires a rebuild against its
matching headers; copying this binary across kernel versions is not supported.
Exclude kernel-build/ from deployment archives; it contains host tooling and
expanded headers rather than board runtime files.
